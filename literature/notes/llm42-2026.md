# LLM-42: Enabling Determinism in LLM Inference with Verified Speculation

**Citation:** Raja Gond, Aditya K. Kamath, Ramachandran Ramjee, Ashish Panwar,
[arXiv:2601.17768](https://arxiv.org/abs/2601.17768), [official code](https://github.com/microsoft/llm-42).

## Mechanism

**Verified fact:** LLM-42 uses a fast decode path, then replays a verification
window under a fixed-shape reduction schedule. Consistent tokens are committed;
mismatches trigger rollback. The verifier's KV entries replace fast-path KV so
the committed state is aligned with the verified computation.

## Contract and limits

**Verified fact:** the primary contract is deterministic repeatability under
dynamic batching, not the original target distribution under stochastic
speculative sampling.

**Author claim:** the scheduling approach can preserve most fast-path behavior
while avoiding the fixed overhead of globally batch-invariant kernels.

**Weak point:** deterministic replay and target-equivalence are related but
different correctness contracts. The same state-localization machinery can
serve both, but the acceptance predicate must be declared separately.

## Mapping

LLM-42 is the closest primary-source analogue for the proposed committed-state
invariant: verify the state that will be used next, not only the emitted text.
