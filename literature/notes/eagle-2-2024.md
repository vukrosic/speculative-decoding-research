# EAGLE-2: Faster Inference with Dynamic Draft Trees

**Citation:** Yuhui Li, Fangyun Wei, Chao Zhang, Hongyang Zhang, EMNLP 2024,
[arXiv:2406.16858](https://arxiv.org/abs/2406.16858).

## Mechanism

**Verified fact:** EAGLE-2 makes the draft tree context-aware. It uses draft
confidence to expand high-value branches and prune low-value branches instead
of using one static tree for every context.

## Claims and evidence

**Author claim:** reported speedup ratios are 3.05–4.26x, described as 20–40%
faster than EAGLE-1, while preserving the target output distribution.

**Weak point:** confidence calibration is an empirical assumption. Dynamic
trees alter the candidate shape and can increase scheduler and memory overhead.

## Mapping

Measure accepted-prefix length conditional on the selected tree, not only the
mean draft acceptance. A fair reproduction must freeze the tree budget and
compare static versus dynamic selection under the same verifier.
