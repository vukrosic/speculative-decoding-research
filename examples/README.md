# Examples

`toy_speculative_decoding.py` is a dependency-free demonstration of drafting,
target verification, first rejection, correction, and target-only comparison.

```bash
python3 examples/toy_speculative_decoding.py --steps 24 --block-size 4
```

Use the real experiment cards and receipts for model-backed work. The toy
example intentionally makes no claim about GPU speed or model quality.
