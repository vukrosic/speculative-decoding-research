## Data and masks

`t`, `t=1..16`, and let `m_{i,t}∈{0,1}` be the frozen valid-position mask from

## Logits and numerical policy

Let `z_{i,t,v}` be the drafter output logit for vocabulary token `v`, with
vocabulary size `V=248,320`. Define `ell_{i,t,v}=log_softmax(z_{i,t,:})_v`
in FP32. For cross-entropy, use `ell` directly. No
temperature, target-logit distillation, stop-gradient, or detached prefix term
is used. Model activations/weights remain BF16; all `log_softmax`, per-position
losses, prefix log sums, and final reductions are FP32. The prefix term clamps
only the selected true-label log probability in log space with fixed
`log_epsilon=log(1e-8)`; no probability tensor, `p̂`, exponentiation, or
probability product is formed, and gradients flow through the FP32 log-softmax
path at all active positions.

## Exact objective

Let label smoothing be `α=0.02` and define the smoothed target distribution

`q_{i,t,v} = (1-α)·1[v=y_{i,t}] + α/V`.

The normalized v27-style position weights are

`a_{i,t} = m_{i,t}/t`, `A_i = Σ_{t=1}^{16} a_{i,t}`.

The weighted hard-label CE component (with smoothing) is

`L_ce(i) = (1/A_i) · Σ_{t=1}^{16} a_{i,t} · (-Σ_v q_{i,t,v}·ell_{i,t,v})`.

Let `K_i = Σ_t m_{i,t}` and define the unsmoothed true-label log probability
directly from the FP32 log-softmax output:
`r_{i,t}=max(ell_{i,t,y_{i,t}}, log_epsilon)`. For each active prefix
length `k=1..16`, compute the cumulative log-survival **without exponentiating**:

`c_{i,k} = Σ_{t=1}^{k} m_{i,t}·r_{i,t}`  (log surviving-prefix probability),

`L_prefix(i) = (1/K_i) · Σ_{k=1}^{16} m_{i,k}·(-c_{i,k})`.

The implementation is frozen to FP32 `log_softmax`, FP32 `r`, FP32 cumulative
sum, FP32 loss terms, and FP32 batch reduction; no `exp`, probability-product,
or reconstructed `S_{i,k}` is computed. Before backward, assert finiteness of
logits, `r`, every `c_{i,k}`, `L_ce`, `L_prefix`, `L_new`, and gradients; any
non-finite value is a fit-gate failure and stops the run.

The proposed replacement objective is

`L_new(i) = L_ce(i) + λ·L_prefix(i)`, with fixed `λ=1.0`.

Batch loss is the arithmetic mean of `L_new(i)` over valid windows. No other
normalization, temperature, clipping, focal factor, or auxiliary loss is
permitted. The prefix term intentionally uses unsmoothed true-label
log probabilities; label smoothing applies only to `L_ce`.
