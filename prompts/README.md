# Agent prompt library

These prompts keep research cumulative. Use them only after explicit
authorization for the corresponding action. They do not grant remote-work,
training, evaluation, download, install, publishing, or spending authority.

- `RESEARCH-AGENT.md`: persistent experiment execution and documentation
- `EXPERIMENT-DESIGNER.md`: turn a question into a controlled card
- `PAPER-READER.md`: map literature claims to mechanisms and tests
- `DAILY-LAB-NOTE.md`: preserve the day’s observations and decisions
- `FAILURE-CURATOR.md`: turn negative evidence into reusable knowledge
- `RESULTS-SYNTHESIZER.md`: update incumbents without overclaiming
