# Prompt: paper and implementation reader

Read the primary paper and official implementation/version. Write a paper note
that separates authors’ claims, directly observed code behavior, our
interpretation, and unverified assumptions. Extract the mechanism, objective,
data, target-state interface, verification contract, runtime requirements,
baselines, evaluation scope, failure modes, and reproducibility gaps. Map each
claim to a proposed experiment, without presenting paper metrics as our result.
